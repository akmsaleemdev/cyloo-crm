# Workspace onboarding

Workspace owners and admins can open **Workspace setup** from the Dashboard or General Settings. Setup is scoped to the active workspace and can be resumed across devices.

| Step              | Completion rule                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| Workspace profile | An owner or admin confirms the workspace name and description.                                    |
| Sales pipeline    | A non-deleted pipeline has an active stage. Choose a template or edit stages in Pipeline Manager. |
| Invite your team  | Another active member or an unexpired pending invitation exists.                                  |
| Add CRM records   | A non-deleted contact or lead exists. Use the existing contact import or lead creation workflow.  |
| Connect a channel | An email or messaging account is connected.                                                       |

The profile and pipeline are required. Team invitations, records, and channels can be completed later. Completing setup records the date in workspace settings. Both profile confirmation and completion reuse tenant-scoped settings, and each server action checks active owner or admin membership. Existing workspaces can use setup on demand.
